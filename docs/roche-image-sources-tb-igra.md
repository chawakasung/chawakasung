## ภาคผนวก — คำศัพท์สำหรับตั้งชื่อไฟล์/ค้นภาพ

| ไทย | อังกฤษ |
|---|---|
| วัณโรคแฝง | Tuberculosis infection (TBI) / Latent TB infection (LTBI) |
| การตรวจวัดการหลั่งอินเตอร์เฟียรอนแกมมา | Interferon-Gamma Release Assay (IGRA) |
| แอนติเจนจำเพาะของเชื้อ | ESAT-6, CFP-10 |
| ทดสอบทูเบอร์คูลินทางผิวหนัง | Tuberculin Skin Test (TST) / Mantoux |
| ระบบอัตโนมัติเต็มรูปแบบของห้องแล็บ | Total Lab Automation (TLA) |
| ระบบสารสนเทศห้องปฏิบัติการ | Laboratory Information System (LIS) |
| การรับรองผลอัตโนมัติ | Auto-verification |
| ระยะเวลารอผล | Turnaround Time (TAT) |
| ผลไม่สามารถสรุปได้ | Indeterminate result |
