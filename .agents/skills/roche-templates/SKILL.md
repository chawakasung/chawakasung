# Roche Templates — self-service brand asset builder

`branding.roche.com/document/29` is the **Templates** section of the Roche Guidelines
portal. It lets anyone at Roche create branded, print-ready or digital assets **without
design experience and without special software** — you edit a template inline in the browser
and download the finished file. Complements [[roche-brand-portal]] (fetch mechanics),
[[roche-design-templates]] (local slide-template library), [[roche-ui]] (web specs),
[[roche-social-ad]] and [[roche-symposium-poster]].

## The most important facts (`#/templates/before-you-start`)

- Assets download as **PDF, JPG, or PNG**.
- **JPG / PNG** → digital & desktop use. **PDF** → printing (send to any print provider).
- Editing is **inline** in the browser: change backgrounds, gradients, keylines, images.
- **Direct download — no approval required.**
- How-to video: `document/33#/overview/how-to-videos-1/templates`.
- Layout codes used across templates: **ABA / BAA / AAB** = the stacking order of
  background (A) vs. content-block (B) bands; the letter count/order sets how big the
  headline/text section is.
- Broken template or new-template request → **corporate.branding@roche.com**.

## When to reach for this skill

The user needs an official Roche deliverable (ad, poster, flyer, email banner, badge,
wordmark, illustration, video graphic) and wants the *sanctioned* template + its exact
size/format, rather than rebuilding from scratch. Point them to the template below; the
editing itself is done live in the portal (open in Chrome Profile 8). If a needed template
doesn't exist, that's the signal to build it on-brand with [[roche-ui]] / [[roche-social-ad]].

### Google Docs — `/google-docs`  (Roche's standard doc tool)

### Word — `/word`  (fallback when Google Docs can't be used)
Windows: template + add-on auto-deployed (else Software Center, needs PulseSecure). All

black=B/W, hide=on pre-logoed stationery), paper size, embed fonts for externals.
**Mac users:** download `.dotx` templates manually (A4 set 01–10, US set 03–10; business
letters, product-logo, double-signature, personal, special-type, blank incl. black).

### Signage — `/signage`  (site-project based; download PDF, print on pre-cut inserts)
- **Door sign** — one layout per room, saved in the site's "Signage" project folder; toggle
  optional layers. Paper: Olin regular high-white matt woodfree ECF 150 g/m², cut **88×178 mm**.
  Fields: room number (max 8 char), optional long room number (max 14, layer 002), room
  designation/employee name (regular = main lang, light = 2nd lang), optional pictogram,
  optional information line (layer 005).
- **Laboratory door sign** — one per lab; cut **184×372 mm** (frame 210×420, insert 184×395,
  visible 178×372). Fields: biosafety level, radionucleotide class, room number (max 10),
  responsibles (max 2), safety info via QR, safety pictograms (Warnings→Prohibitions→
  Mandatories, max 12), optional info box (layer 100/200). **Only authorised persons
  (local SHE) may create/edit lab signs.** Existing projects listed by site (e.g. Basel,
  Rotkreuz); site not listed → email corporate.branding@roche.com.

### Badges — `/badges`  (Personal ID; final PDF has 3 mm bleed)
Photo: face-on, sharp, centred, whole face, **light-grey monochrome background**.
Keyline colour encodes type:
- **Internal** — Roche Blue keyline (Purpose Statement on back)
- **External** (contractors) — Dark Red keyline (+ validation date)
- **Construction site** — Orange keyline (+ validation date; emergency/access info on back)
- **Visitor** — Light Red keyline (+ "Temporary badge", validation date/time, Roche host name;
  optional QR in a white box)
Full spec: `20250124_Roche_Guidelines_Employee_Personal_Identification_e1.pdf`.

### Email signature — `/email-signature`  (**text only — no images/logos allowed**)
Gmail: use **"Sans Serif Normal"** (Google has no custom fonts). Structure: 1) Name (bold) +
title (matches HR profile; optional pronouns); 2) Company info; 3) Sender info; 4) optional
absences/working days; 5) optional up to 3 CTA links (Roche-owned, externally accessible);
6) **Confidentiality Note verbatim in English** (Sans Serif Small). Legal nomenclature (if
required by law, legal-approved) sits above it. Replies/forwards: name + phone suffice.
**Forbidden:** non-black colours, other fonts, italic/underline, any logo, promos/banners/
slogans/quotes, icons (phone/smiley/envelope), coloured/patterned backgrounds, Purpose
Statement, pipeline info.

## 3. Wordmark generator — `#/wordmark-generator/wordmark-templates`

  `.fig`, `.ai`. ⚠️ Figma illustrations are **PNG not vector** — edit artwork in the **`.ai`** files.
- Feedback / new characters-objects-templates: dedicated request form on the page.

# Access reminder

Every page is Roche-SSO-gated. Fetch/browse only via the authenticated Chrome **Profile 8**
headless dump in [[roche-brand-portal]] (quit Chrome first; restore after). Always fetch the
specific `#/…` route — landing bodies are "Lorem ipsum" placeholder. Support:
**corporate.branding@roche.com** (social media: **global.social_media@roche.com**).

**Stubborn routes that `--dump-dom` returns as 0 bytes** (seen on `/social-media`): the page
pins the virtual clock with never-settling external requests (social embeds), so
`--virtual-time-budget` never elapses and nothing dumps. CDP/remote-debugging is blocked by
Roche's Chrome policy on Profile 8, so the fix is to **fail all non-Roche hosts** so the clock
advances, e.g. add:
`--host-resolver-rules="MAP * ^NOTFOUND, EXCLUDE branding.roche.com, EXCLUDE *.roche.com, EXCLUDE *.ffycdn.net, EXCLUDE *.frontify.com, EXCLUDE *.frontifyapp.com, EXCLUDE fonts.googleapis.com, EXCLUDE fonts.gstatic.com"`
to the headless command. That recovered the full 1.1 MB `/social-media` DOM.
